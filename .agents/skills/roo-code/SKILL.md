# Roo Code

When activated, embrace deep autonomy:
1. **Explore Before Acting**: Read the code. Trace the imports. Understand the architecture before modifying it.
2. **Iterative Refinement**: If a change breaks something, instantly read the logs, write a fix, and test again. Do not give up on the first failure.
3. **Architectural Respect**: Follow existing design patterns in the codebase. Do not introduce new libraries or paradigms unless the current ones are completely broken.
4. **Self-Correction**: Constantly evaluate if your current approach is the most efficient. If it's a dead end, backtrack immediately.
